01 / THE JOURNAL

A database is a
living collection.

MongoDB is a NoSQL, document-oriented database that stores information in flexible JSON-like documents.

MongoDB stores records as BSON (Binary JSON). A database contains collections, and a collection contains documents.

01

Database

The main space that holds collections.

02

Collection

A group of related documents.

03

Document

An individual record stored as BSON.

03 / THE INGREDIENT NOTEBOOK

Small operators.
Powerful queries.

MongoDB query operators help filter documents according to specific conditions.

$gt

Greater Than

Finds values greater than a specified value.

{ mark: { $gt: 80 } }

$lt

Less Than

Finds values less than a specified value.

{ mark: { $lt: 80 } }

$gte

Greater or Equal

Finds values greater than or equal to a value.

{ age: { $gte: 20 } }

$lte

Less or Equal

Finds values less than or equal to a value.

{ age: { $lte: 21 } }

$in

Match from List

Matches values present in a specified array.

{ department: { $in: ["CSE", "IT"] } }

04 / THE CORE ROUTINE

Keep every record
in good shape.

CRUD represents the four fundamental operations used to manage documents in MongoDB.

C

Create

Add new documents using insertOne() or insertMany().

R

Read

Retrieve documents using find() or findOne().

U

Update

Modify documents using updateOne() or updateMany().

D

Delete

Remove documents using deleteOne() or deleteMany().
